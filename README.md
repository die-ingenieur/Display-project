# mini-gamer conole
This is designed to be a mini game console you can easily carry around with and play two one of snake or flappy bird :).
This design incorporates 4 buttons which you can use to control movement and select menu option acting as left, up , right , down.

## Why's i make this?
Because when i get bored, it would be nice for a toy to play on.

## how to make
1. first order (or make) the pcb using the gerber files and schematics
2. solder components to their corresponding holes
3. upload code and then you are done
